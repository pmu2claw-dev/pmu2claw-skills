# AFC (Adaptive Fast Charging) 快充協議

## 1. 簡介
*   **制定者**: Samsung (三星)
*   **核心目標**: 提供 9V 高壓快充 (最高 15W, 9V/1.67A)，與高通 QC 2.0 競爭/共存。
*   **應用場景**: 廣泛用於 Galaxy S6 ~ S10 世代的附贈充電器與手機。

## 2. 物理層與握手流程
*   **通訊媒介**: 利用 USB 介面的 **D+ / D-** 腳位。
*   **通訊方式**: 握手與電壓協商過程與高通 QC 2.0 極度相似。
*   **差異**: 雖然底層觸發原理（D+ 施加電壓，等待 D- 回應）與 QC 2.0 類似，但具體的識別時序、驗證信號長度有微小差異，導致早期某些純 QC 充電器無法觸發三星手機的 AFC，反之亦然。不過現代的多協議控制器通常能同時相容並正確識別兩者。

## 3. 演進
*   隨著 USB PD 普及，三星在近年的 Galaxy S 系列 (S20 之後) 已全面轉向 **USB PD 3.0 PPS** (Super Fast Charging, SFC)，提供 25W (9V/2.77A) 或 45W (11V/4.05A) 的充電能力。AFC 目前僅作為舊設備的相容協議保留在充電器中。
