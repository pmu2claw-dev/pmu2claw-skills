# QC (Quick Charge) 快充協議

## 1. 簡介與版本
*   **制定者**: Qualcomm (高通)
*   **核心目標**: 透過提高電壓來降低電流，減少傳輸線損耗，達到快速充電。
*   **版本演進**:
    *   **QC 1.0**: 5V/2A，不涉及電壓調整，主要透過 D+/D- 短路識別。
    *   **QC 2.0**: 導入高壓模式，支援 5V, 9V, 12V (甚至 20V，少見)。最大功率 18W (通常為 9V/2A 或 12V/1.5A)。
    *   **QC 3.0**: 導入 INOV (Intelligent Negotiation for Optimum Voltage) 演算法。電壓以 200mV 為一階進行動態調整，範圍為 3.6V 到 12V (或 20V)，大幅提高充電效率並減少發熱。
    *   **QC 3+**: 支援更細緻的電壓協商，在既有 QC3.0 基礎上加入 Source Capability 廣播 (利用 `+-+-+-` 查詢，`++--` 確認)。
    *   **QC 4.0 / 4.0+**: 放棄了基於 D+/D- 的電壓階梯協商，轉向相容 USB PD (Power Delivery) 3.0 與 PPS (Programmable Power Supply)。
    *   **QC 5**: 支援 100W+，完全基於 USB PD EPR/PPS。

## 2. 物理層實作 (QC 2.0 / 3.0)
*   **通訊媒介**: 利用 USB 介面的 **D+ / D-** 腳位。
*   **通訊方式**: 類比電壓階梯 (Analog Voltage Stepping)。
*   **硬體要求**: Controller 需要內建 ADC / 比較器 (接收端) 與 DAC / 電阻分壓網路 (發送端) 來在 D+/D- 上施加與讀取特定電壓。

## 3. 協議層與握手流程 (Handshake)

### QC 2.0 狀態機與電壓對應
設備插入後，QC 2.0 的標準握手流程如下：
1.  **初始狀態 (5V)**: 設備 (Sink) 啟動，D+ 和 D- 為 0V (或由 BC1.2 控制)。
2.  **BC1.2 檢測**: 設備在 D+ 施加 0.6V，若 D- 也出現 ~0.6V (充電器端短接 D+/D-)，則識別為 DCP (Dedicated Charging Port)。
3.  **QC 觸發**: 設備維持 D+ = 0.6V 至少 1.25 秒。若充電器支援 QC，會將 D- 斷開短接並下拉到 GND (0V)。設備檢測到 D- 變為 0V 後，確認進入 QC 模式。
4.  **電壓請求**: 設備透過改變 D+ 與 D- 的電壓組合，向充電器請求特定輸出電壓：

| D+ 電壓 | D- 電壓 | 請求的 VBUS 輸出電壓 (QC 2.0) |
| :--- | :--- | :--- |

### QC 3.0 / 3+ 動態調整 (Continuous Mode)
1.  **進入連續模式**: 在 QC 2.0 狀態下，將 D+ 設為 0.6V，D- 設為 3.3V。
2.  **電壓調整**: 
    *   **增加電壓 (+200mV)**: D+ 維持 0.6V，D- 從 3.3V 下拉到 0.6V 再回到 3.3V (產生一個脈衝)。
    *   **降低電壓 (-200mV)**: D- 維持 3.3V，D+ 從 0.6V 下拉到 0V 再回到 0.6V (產生一個脈衝)。
3.  **QC 3+ 協商**: Sink 可發送特定的脈衝序列 (如 `+-+-+-`) 查詢 Source 的能力，若 Source 回應，Sink 再以 `++--` 確認進入 QC3+ 模式。

### 時序與閾值要求
*   **電壓變化穩定時間 (T_V_CONT_CHANGE)**: 每次 200mV 步進調整後，Source 需在特定時間內穩定電壓。
*   **脈衝寬度 (T_ACTIVE, T_INACTIVE)**: D+/D- 上的脈衝寬度有嚴格規定，過短 (Glitch) 應被濾除，過長可能被判定為狀態改變。
| 0.6V | 0V | 5V (預設) |
| 3.3V | 0.6V | 9V |
| 0.6V | 0.6V | 12V |
| 3.3V | 3.3V | 20V (少見) |

*(註：0.6V 實際上是 0.325V 到 2.0V 之間的容忍範圍；3.3V 通常大於 2.0V)*

### QC 3.0 INOV 狀態機
QC 3.0 沿用 QC 2.0 的進入流程。在進入 QC 模式後，若設備將 D+ 和 D- 組合設為 **0.6V 和 3.3V**，則啟動連續模式 (Continuous Mode)。
*   在連續模式下，設備透過在 D+ / D- 上產生「脈衝 (Pulse)」來微調電壓。
*   **D+ 脈衝 (3.3V -> 0.6V -> 3.3V)**: 要求 VBUS 增加 200mV (Increment)。
*   **D- 脈衝 (3.3V -> 0.6V -> 3.3V)**: 要求 VBUS 減少 200mV (Decrement)。

## 4. 多協議共存
*   QC 2.0/3.0 是最廣泛實作的私有協議之一。
*   當 Type-C 充電器同時支援 PD 與 QC 時，必須先執行 PD 協商。若 CC 腳沒有建立 PD 連接 (例如接上 A-to-C 線或設備不支援 PD)，充電器才會在 D+/D- 上回應 QC 的 0.6V 握手請求。
