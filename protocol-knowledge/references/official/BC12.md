# BC1.2 (Battery Charging 1.2)

## 1. 簡介
*   **制定組織**: USB-IF
*   **歷史背景**: 在 Type-C 與 USB PD 出現之前，為了解決標準 USB 2.0 只能提供 500mA，無法滿足智慧型手機充電需求而制定的標準。
*   **核心目標**: 將最大安全充電電流從 500mA 提升至 **1.5A (固定 5V)**。

## 2. 物理層實作與連接埠類型
BC1.2 完全利用 **D+ / D-** 進行硬體層級的類比電壓與電阻檢測。定義了三種連接埠類型：

1.  **SDP (Standard Downstream Port)**:
    *   **定義**: 標準 USB 數據接口 (如舊款電腦 USB 孔)。
    *   **行為**: 支援 USB 數據傳輸。未枚舉前最大 100mA，枚舉後最大 500mA (USB 2.0) 或 900mA (USB 3.0)。
    *   **識別**: D+ 與 D- 各自透過 15kΩ 下拉至地。
2.  **CDP (Charging Downstream Port)**:
    *   **定義**: 支援大電流充電的 USB 數據接口。
    *   **行為**: 同時支援 USB 數據傳輸與高達 1.5A 的充電電流。
    *   **識別**: 當設備在 D+ 施加 0.6V (VDAT_SRC) 時，主機端內部電路會回應，使得 D- 也出現約 0.6V 的電壓。
3.  **DCP (Dedicated Charging Port)**:
    *   **定義**: 專用充電器 (不支援數據傳輸)。
    *   **行為**: 最大可提供 1.5A (甚至更高，受限於接頭)。
    *   **識別**: 充電器內部將 **D+ 與 D- 短路 (短接阻抗 < 200Ω)**。當設備在 D+ 施加電壓時，D- 會立刻反映相同的電壓。

## 3. 測試與多協議優先級
*   幾乎所有的私有協議 (如高通 QC 2.0/3.0、三星 AFC、華為 FCP) 都是建立在 BC1.2 的基礎上。
*   **握手順序**: 當手機插入充電器，若不走 PD，通常會先進行 BC1.2 檢測。一旦確認 D+/D- 短路 (識別為 DCP)，手機才會進一步在 D+/D- 上施加特定電壓或脈衝，嘗試喚醒 QC 或其他高壓私有協議。
