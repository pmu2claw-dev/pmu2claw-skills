# FCP / SCP (Huawei) 快充協議

## 1. FCP (Fast Charge Protocol)
*   **制定者**: Huawei (華為)
*   **特性**: 類似高通 QC 2.0，屬於高壓小電流方案 (例如 9V/2A = 18W)。
*   **實作方式**: 透過 **D+ / D-** 進行類比信號握手與電壓請求。
*   **狀態與時序**: 與 QC 非常相似，設備端透過改變 D+/D- 電壓組合來請求 5V 提升到 9V。

## 2. SCP (Super Charge Protocol)
*   **制定者**: Huawei (華為)
*   **特性**: 屬於低壓大電流直充方案 (例如 5V/4.5A, 4.5V/5A, 或後期的 10V/4A, 11V/6A)。
*   **實作方式**:
    *   **通訊媒介**: 同樣透過 **D+ / D-** 進行通訊。
    *   **通訊方式**: 不同於 FCP/QC 的靜態電壓組合，SCP 採用類似 UART 的**數位脈衝通訊** (Digital Pulse Communication) 在 D+/D- 上進行封包交換，類似後來 UFCS 的做法。
    *   **握手流程**:
        1. 插入後預設為 5V。
        2. 設備透過 D+/D- 發送特定序列，詢問充電器能力。
        3. 充電器回應支援 SCP。
        4. 設備根據電池狀態，透過封包請求微調 VBUS 電壓與電流限制。
    *   **特點**: 由於是大電流直充，充電器直接承擔降壓發熱，手機內部僅由 Charge Pump 進行電流轉換，大幅降低手機端發熱。

## 3. 多協議共存
*   支援 Huawei 快充的第三方晶片 (如某些 Charger IC 或 Power Bank SOC) 需要同時實作 FCP 的類比狀態機與 SCP 的數位解碼器。
