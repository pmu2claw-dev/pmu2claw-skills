# PE (Pump Express) 快充協議

## 1. 簡介
*   **制定者**: MediaTek (聯發科)
*   **核心目標**: 透過改變充電器輸出電壓，提供更大的充電功率，避免受限於 Micro-USB 時代的 2A 電流限制。
*   **版本演進**: PE 1.0 (5V/7V/9V), PE 2.0 (5V~20V, 0.5V/step), PE 3.0 / 4.0 (轉向 USB PD PPS，類似直充概念)。

## 2. 物理層實作 (PE 1.0 / 2.0)
PE 1.0/2.0 的實作方式非常獨特，完全不依賴 D+ / D- 數據線，這使得它能相容於只有 VBUS 和 GND 兩根線的劣質充電線。
*   **通訊媒介**: 利用 **VBUS (電源線)** 進行通訊。
*   **通訊方式**: **負載電流調變 (Current Pulsing)** 或稱為 VBUS 載波。
*   **發送端 (Sink, 手機)**: 手機內部的充電 IC 透過快速接通與斷開充電電流 (產生 Current Pulses)，在 VBUS 上製造出特定的負載波動型樣。
*   **接收端 (Source, 充電器)**: 充電器內部的初級端控制器 (Primary-side Controller) 偵測到輸出電流的特定頻率脈衝後，將其解碼為指令，然後調整變壓器的輸出電壓。

## 3. 測試與除錯含意 (Test/Debug Implications)
*   **測試困難度**: 因為通訊混合在電源波形中，用邏輯分析儀無法直接解析，必須使用示波器配合電流探棒 (Current Probe) 擷取 VBUS 電流波形，並手動或利用特定軟體計算脈衝寬度來解碼。
*   **時序特徵**: PE 的脈衝週期極長 (相對於 MHz 等級的數位通訊)，一個完整的指令週期可能長達 2 秒。這表示電壓調整的反應速度較慢。

## 4. 演進
由於 VBUS 載波通訊容易受到雜訊干擾，且反應速度慢，聯發科從 PE 3.0 開始放棄此架構，轉而擁抱 Type-C CC 腳與 USB PD 協議。現代設備已極少見到 PE 1.0/2.0。
